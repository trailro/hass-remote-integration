Parent Home Assistant

The HA that consumes what this container publishes. Reached over its websocket API with a long-lived access token (Profile → Security → Long-lived access tokens); the token is stored write-only in integration_manager/settings.json (mode 600) and used only to read its entity/device registries and states, and to remove orphans of ours when you ask.

Parity

Entities are matched by discovery unique_id (<prefix><entity_id here>), which survives renames on the parent. missing = announced here, absent there · orphans = there under our prefix, no longer announced here · state mismatches compare the current state on both sides.

Assisted cutover

The day you stop the integration on the parent and let this container feed it: preconditions → discovery on (full republish) → wait for the parent to create the entities → compare. Undo switches discovery off and clears every retained discovery config of this identity, so the parent removes the entities again; the retained state documents stay.
