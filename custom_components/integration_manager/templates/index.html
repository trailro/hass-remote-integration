Integration one per container

This container holds one integration, with as many of its versions in the store as you like. Start deploys the chosen version (files to custom_components, requirements into the venv, patches applied, config entries the manager disabled enabled again; an entry you disabled stays disabled); another version runs its preflight first, and blockers ask before starting anyway. Switching versions keeps the config entries. Versions come from the Install page; installing a different integration there replaces this one (after a backup). Another integration = another container.
