Formatting

By default every line is shown whole. A format splits lines into columns. It is a JSON object with these keys:

  • pattern (required): a Python regular expression matched at the start of each line. Every named group (?P<name>…) becomes a column, in the order it appears. Lines that do not match are shown whole.
  • hide: group names that are captured but not shown.
  • dim: group names shown in a muted colour.
  • color_by and colors: the value of the color_by group picks the row colour from colors. Colours: ok, warn, bad, accent, muted. Values that are not listed keep the default colour.

Inside JSON every backslash is written twice, so \S+ becomes \\S+. The format is checked on save, stored in integration_manager/settings.json and kept in backups. The filter always searches the whole line, hidden groups included. Leave the box empty and save to go back to whole lines. Matching has a time limit of 2 seconds per refresh: when a pattern is too slow for the lines on screen, the remaining lines are shown whole and the page says so.
