Health rules

The health verdict published on hass_<domain>/health (and used by the smoke test) comes from what this process sees of the running integration's entities. Defaults apply to every integration; a row overrides them for one. periodic integrations write states all the time (a quiet bus is a fault after stale seconds); event integrations only write on events, so silence is not a fault for them. stale basis (periodic integrations only: an event one is never judged on silence) says what counts as a sign of life: reported (default) is any state write, even an unchanged value; updated is a value or attribute that changed. Pick updated for an integration whose coordinator keeps re-writing the same states after its source died (the entry stays loaded, nothing new arrives), with a stale longer than the quietest normal stretch.
